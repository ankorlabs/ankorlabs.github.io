The studio

Ankor Labs is an independent software studio founded by Shaul Zlotnick. We design and build practical tools for work in the real world.

Ankor Labs

The name

Ankor, from anchor.

Ankor takes its name from the anchor. There's something we love about an object so modest being trusted with something so much larger than itself.

It's a fitting ambition for an independent software studio. A well-made tool can give one person the capabilities of a team, or turn a project that felt out of reach into something they can actually do. We want to build software that has that kind of significance in someone's hands.
